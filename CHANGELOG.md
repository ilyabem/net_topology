# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]
### Added
- **Список IP-адресов в Excel** (`.xlsx`): строка на каждый найденный IP,
  включая все интерфейсы мультиинтерфейсных устройств. Колонки: подсеть, имя,
  ОС, предполагаемый тип, уверенность, «почему такой тип» (понятным языком),
  MAC, производитель, открытые порты с названиями служб, шлюз, хопы, другие
  IP устройства. Закреплённая шапка, автофильтр, цвет по типу и уверенности,
  лист «Сводка» (по типам, ОС, подсетям). Меню «Экспорт» и `--export *.xlsx`.

### Security
- Защита от формул-инъекций: значения из сети (имена хостов и т.п.) в XLSX
  сохраняются как текст, в CSV экранируются.

## [2.0.0] - 2026-11-03
### Added
- **Раскладка без наложений** (`layout.py`, без numpy): «Дерево ↓», «Дерево →»,
  «Органическая». Ветки дерева занимают отдельные полосы, много листьев —
  сеткой, связи «гребёнкой» по зазорам: карточки не перекрываются, линии не
  проходят через чужие узлы. Если сдвинуть узел вручную, связь остаётся ортогональной.
- **Иерархические связи** вместо «звезды»: шлюз → коммутатор → устройства,
  цепочка маршрутизаторов до удалённых подсетей, виртуальный узел «Сегмент сети»,
  приоритет достоверных связей (LLDP/CDP/FDB/ARP) над предполагаемыми.
- **Определение ОС** и **уверенность классификации** с пояснением
  («почему такой тип»), оценка числа хопов по TTL.
- Новые типы: точка доступа, IP-камера, NAS, IoT, сегмент сети.
- **Экспорт** (`exporters.py`): интерактивный HTML в одном файле (масштаб,
  поиск, фильтр, карточка устройства), SVG, draw.io, GraphML для yEd/Gephi,
  CSV-инвентаризация; из GUI — векторный PDF и PNG. CLI: `--export`, `--layout`.
- **Новый GUI**: панели «Сканирование», «Устройства» (дерево с поиском),
  «Свойства», «Журнал»; прогресс и остановка сканирования; векторные иконки
  (`visual.py`), бейджи, зоны подсетей; масштаб под курсором, панорама,
  скрытие подписей при отдалении; сохранение настроек; drag & drop проекта.
- Формат проекта **JSON v2** (метаданные, маршруты линий), атомарная запись;
  файлы v1 открываются.
- ~65 новых тестов, включая смоук-тест GUI.

### Fixed
- OUI-база не скачивалась: адрес Wireshark manuf (gitlab) отдавал 404.
- Записи OUI MA-M/MA-S (`/28`, `/36`) разбирались неверно и приписывали
  производителя подблока всему OUI.
- Ложные совпадения производителей по подстроке («hp» в «Shpe») —
  теперь по границам слов; короткие слова в имени хоста — как отдельные слова.
- `iphone` определялся как VoIP-телефон.
- Случайный (LAA) MAC перевешивал известного производителя.
- Объединение по MAC склеивало десятки IP за proxy-ARP в одно устройство.
- Загрузка файла с частью узлов без координат сбрасывала ручную раскладку.
- Вывод в консоль Windows падал на символах `→` / `★`.
- CI не запускался (ветка `main` вместо `master`, неверный путь к тестам);
  удалён дублирующий `test_topology.py` в корне.
- `pysnmp==4.4.12` ставится только на Python ≤ 3.11; `numpy` больше не нужен.
- SNMP молча не работал: `pysnmp 4.4.12` несовместим с `pyasn1` ≥ 0.6.1 —
  версия `pyasn1` закреплена.
- `pip install -r requirements.txt` падал на Windows (кириллица в комментариях
  при кодировке cp1252) — файл переведён в ASCII. CI ставит зависимости
  именно из него.

## [1.3.0] - 2026-05-25
### Added
- **Мобильные устройства** (`mobile_device`) — новый тип для Android/iOS устройств
  с рандомизированными MAC-адресами (LAA). Windows 11 с LAA + TTL=128 корректно
  определяется как `windows_endpoint`, а не мобильное.
- **Hostname-эвристика** — определение ОС по имени хоста: `msi-*`, `ubuntu-*`,
  `debian-*`, `DESKTOP-*`, `iphone`, `galaxy` и другие паттерны.
- **Адаптивный layout** — размер canvas масштабируется под число узлов
  (`max(800, 90×√n)` пикселей). При 18 узлах минимальное расстояние ≥ 96px.
- **`_spread_overlapping()`** — алгоритм принудительного разведения узлов,
  исключает наложение иконок при плотных топологиях.

### Fixed
- Наложение узлов друг на друга при большом количестве устройств в сети.
- Устройства с рандомизированными MAC определялись как `unknown` — теперь `mobile_device`.
- Сканирующий хост (без MAC в ARP) определяется по hostname.

## [1.2.0] - 2026-05-24
### Added
- **OUI-база производителей** (`oui_db.py`) — локальный кэш ~39 000 записей.
  Источники: Wireshark manuf + IEEE OUI CSV. Авто-обновление раз в 60 дней.
- **`--update-oui`** — CLI-флаг для ручного обновления базы.
- **Кнопка обновления OUI** в GUI (Правка → 🔄 Обновить OUI-базу...).
- **VoIP-телефоны** (`voip_phone`) — новый тип, голубой шестиугольник.
  Определяются по OUI (Grandstream, Yealink, Polycom, Snom, Fanvil...).
- **Gateway-эвристика** — IP оканчивающийся на `.1` или `.254` получает
  буст +4.5 к типу `router`.
- **Расширенные типы устройств**: `windows_server`, `linux_server`,
  `windows_endpoint`, `linux_endpoint`, `printer` вместо общих `server`/`endpoint`.

### Fixed
- `192.168.x.1` определялся как `linux_server` из-за портов 80/443 — исправлено gateway-эвристикой.
- KYOCERA Display, Pantum, Grandstream определялись неверно — добавлены в OUI-правила.
- pysnmp 7.x (lextudio) несовместим со старым sync API — добавлен автодетектор версии.

## [1.1.0] - 2026-05-22
### Added
- **Поддержка нескольких подсетей** (`--subnets 192.168.1.0/24 10.0.0.0/24`).
- **Параллельное сканирование** (`--parallel`) через `ThreadPoolExecutor`.
- **Мультиинтерфейсные устройства** — автоматическое объединение узлов
  с одинаковым MAC (`merge_by_mac()`). Золотистая двойная рамка в GUI + символ ★.
- **Ручное объединение/разделение** узлов через контекстное меню.
- **Фильтр типов устройств** — выпадающий список с чекбоксами, мгновенное
  скрытие/показ без пересканирования. Группы: сетевое / серверы / конечные точки / мобильные.
- **Сканирование в фоне** (`QThread`) — GUI не зависает во время скачивания.
- **`normalize_mac()`** — нормализация MAC из форматов Linux/Windows/Cisco.

### Fixed
- Циклический импорт `gui.py` ↔ `net_topology.py` — исправлен lazy-импортом.
- `Device.from_dict()` дублировал интерфейсы при десериализации.

## [1.0.0] - 2026-05-11
### Added
- Сканирование сети через ARP (Scapy) и ping (nmap).
- Определение типов устройств: router, switch, firewall, bridge, server, endpoint.
- Взвешенная классификация: SNMP + порты + TTL + OUI.
- Граф топологии на NetworkX со spring layout.
- GUI на PyQt5: перетаскивание узлов, контекстное меню, сохранение/загрузка JSON.
- Экспорт в JSON и GraphML.
- CLI-режим (`--no-gui`) с текстовой таблицей.
- Юнит-тесты (pytest).
